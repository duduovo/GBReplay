# Release checklist

- [x] Core source copied from the final GBReplay implementation.
- [x] Paper experiment runners default to five repetitions.
- [x] Datasets, checkpoints, memory banks, logs, and virtual environments excluded.
- [x] Ablation, diagnostic, reviewer-control, and comparison-method code excluded.
- [x] README, license, citation metadata, and experiment mapping included.
- [x] Hard-coded local paths removed from release scripts.
- [x] Python files pass syntax compilation.
- [x] Core modules pass an import smoke test in the tested environment.
- [ ] Re-run the complete public five-repeat suite in a clean environment.
- [ ] Add paper DOI/journal metadata after publication.
- [ ] Create a versioned GitHub release after verification.
